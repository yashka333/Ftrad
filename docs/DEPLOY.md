# Как выложить игру на Render

Render даёт бесплатный сервер и бесплатную базу Postgres. Всё настраивается из файла `render.yaml` в корне репозитория.

## 1. Залить код на GitHub

Код должен лежать в твоём репозитории на GitHub (например `Ftrad`). Через GitHub Desktop: внести изменения → Commit to main → Push origin.

## 2. Создать сервис на Render

1. Открой render.com и войди через GitHub (Sign in with GitHub).
2. Render попросит доступ к репозиториям: разреши доступ к `Ftrad`.
3. Нажми New → Blueprint.
4. Выбери репозиторий `Ftrad` и нажми Connect.
5. Render покажет, что создаст: веб-сервис `frogotraderz` и базу `frogotraderz-db`. Нажми Apply.
6. Подожди 3-5 минут, пока идёт сборка. Когда статус станет Live, открой ссылку вида `https://frogotraderz.onrender.com`.

Эту ссылку можно отправить другу. Ссылка с приглашением берётся на экране INVITE внутри игры.

## 3. Обновления

Когда в репозиторий приходят новые изменения (Push origin), Render сам пересобирает и перезапускает игру. Прогресс игроков хранится в базе и не пропадает.

## Что важно знать про бесплатный тариф

- Если игру никто не открывает 15 минут, сервер засыпает. Первое открытие после сна занимает около минуты. Жабы при этом не теряют заработок: сервер досчитывает всё, что было, пока он спал.
- Бесплатная база Render живёт 30 дней. Для теста этого хватает. Потом её нужно продлить на платном тарифе или создать новую (тогда прогресс начнётся заново).

## Настройки

Render → сервис `frogotraderz` → Environment:

- `TIME_SCALE`: поставь `10`, чтобы смены и отдых шли в 10 раз быстрее (удобно показывать игру). `1` значит реальное время.
- `DEV_MODE`: `true` значит тестовый баланс и кнопка TEST DEPOSIT.

После изменения нажми Save Changes, Render перезапустит игру.

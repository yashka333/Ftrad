# Frogotraderz

AFK-игра в пиксельном стиле на Solana. Открываешь паки, получаешь жаб, сажаешь их за столы в трёх офисах. Жабы торгуют и зарабатывают $FROG, даже когда игра закрыта. Уставшие жабы бесплатно отдыхают в казино.

Сейчас это первый прототип. Вход через Phantom настоящий, а баланс тестовый: новый игрок получает 500 000 тестовых $FROG, кнопка TEST DEPOSIT добавляет ещё.

## Что есть в игре

| Экран | Что там |
| --- | --- |
| Login | Вход через Phantom: кошелёк подписывает сообщение, транзакции нет |
| Shop / Recruit | Паки по 1, 5, 10, 15 жаб, 10 000 $FROG за пак, открытие карточек |
| Frogs | Вся команда: назначить стол, работать, отдыхать, ALL TO WORK, ALL TO CASINO |
| Go to work | Три офиса по 5 столов, жабы за столами, заработок в реальном времени |
| Casino | Бесплатный отдых для уставших жаб |
| Market | Торговля только Legendary и Mythic, комиссия 5% сжигается |
| Invite | Друг купил 10 жаб: тебе 1 бесплатный пак, за каждые следующие 10: ещё 2 |
| Wallet | Баланс, заработок, вывод (раз в сутки, от 100 000, комиссия 3%), выход |
| Boss Frogs | Заглушка «Announcement soon» |

## Выложить на Render (бесплатно)

Пошаговый гайд в [docs/DEPLOY.md](docs/DEPLOY.md). Коротко: render.com → New → Blueprint → выбрать этот репозиторий → Apply. Render сам создаст сервер и базу по файлу `render.yaml`.

## Запустить у себя

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:8787. Без `DATABASE_URL` мир хранится в `server/data/world.json`.

| Команда | Что делает |
| --- | --- |
| `npm test` | Тесты правил и API |
| `npm run typecheck` | Проверка типов |
| `npm start` | Запуск сервера: API и страница игры |
| `npm run client` | Пересобрать страницу игры `server/public/index.html` (нужен Python 3 с Pillow и numpy) |

## Настройки сервера

| Переменная | Что значит |
| --- | --- |
| `SESSION_SECRET` | Ключ для подписи сессий, 32+ символов. В Render создаётся сам |
| `DATABASE_URL` | Postgres. Если пусто, мир хранится в JSON-файле |
| `DEV_MODE` | `true`: тестовые $FROG новым игрокам и кнопка TEST DEPOSIT |
| `TIME_SCALE` | Ускорение времени для тестов: `10` значит смены и отдых в 10 раз быстрее |

## Структура

```
shared/            правила игры, общие для сервера и клиента
  src/config.ts      все цифры экономики: паки, вывод, маркет, инвайты
  src/rarity.ts      редкости, шансы, статы
  src/skills.ts      14 навыков
  src/actions.ts     все действия игрока
  src/simulate.ts    как жабы работают, устают и отдыхают
server/            API на Fastify
  src/routes/        auth (Phantom), game, market, invite
  src/store/         хранение мира: Postgres или JSON-файл
  public/            собранная страница игры
  test/              тесты API, входа через кошелёк, маркета, инвайтов
tools/art/         пиксель-арт на Python и движок экранов
  demo/              JS экранов: офисы, казино, карточки, маркет, инвайт, вход
client/src/assets/ готовые PNG и layout.json всех экранов
docs/              экономика, деплой
```

Баланс меняется в `shared/src/config.ts` и `shared/src/rarity.ts`. Подробно про экономику: [docs/economy.md](docs/economy.md).
